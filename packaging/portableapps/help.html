scrcpy-launcher Portable

Reusable scrcpy sessions from the Windows notification area.

Using the application

Start scrcpy-launcherPortable.exe. Right-click its notification-area icon to launch a saved session, open Settings, check for updates, view About information, or quit.

Connect an Android device with USB debugging enabled. Open Settings to detect devices, create sessions, select installed Android applications, and choose commonly used scrcpy options.

Portable data

Configuration, backups, recovery files, and logs are stored beneath the package's Data directory. The application does not enable Windows autostart in the PortableApps.com edition.

You may move the complete scrcpy-launcherPortable directory between folders or drive letters. Close the tray application and all launched scrcpy sessions before moving, ejecting, or upgrading it.

Updates

Install a newer PortableApps package over the existing directory. The PortableApps.com Installer preserves Data during upgrades. A custom scrcpy executable path is specific to the Windows computer and location where it was selected; the bundled runtime is recommended for portability.

Licensing and support
