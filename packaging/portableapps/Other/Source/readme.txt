scrcpy-launcher Portable package source information
===================================================

The base application's complete source code, release history, and build
instructions are available at:

https://github.com/wwalsh/scrcpy-launcher

scrcpy-launcher is licensed under GPL-3.0-only. The application package also
contains separately licensed third-party components, including scrcpy and
Android SDK Platform-Tools. Their notices and license texts are distributed
inside App\scrcpy-launcher.

The portable launcher is generated without custom NSIS code from
App\AppInfo\Launcher\scrcpy-launcherPortable.ini using the unmodified
PortableApps.com Launcher. The launcher is GPL-2.0-or-later; its license text
is included in this directory as launcher-license.txt. PortableApps.com
Launcher source and documentation are available at:

https://portableapps.com/development

The .paf.exe package is generated using the unmodified PortableApps.com
Installer. User configuration is stored in Data and is preserved during
package upgrades.
